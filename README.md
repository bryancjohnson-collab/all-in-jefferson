# All In Jefferson

A short browser game for the camp crew: keep the fire going from dusk to dawn, or the campers go to bed and the bear comes.

Play it: https://bryancjohnson-collab.github.io/all-in-jefferson/

Follow-up to [Storm Camp](https://github.com/bryancjohnson-collab/storm-camp). Nature models from Kenney's Nature Kit (CC0, license in `assets/models/`).
